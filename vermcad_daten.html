📥 Datenimport & Datenverwaltung

Grundlage für die weitere Bearbeitung

Die Qualität eines Vermessungsprojektes hängt stark von den verwendeten Ausgangsdaten ab. Vor der Bearbeitung müssen Daten geprüft, korrekt übernommen und anschließend kontrolliert werden.

📌 Welche Daten werden in VermCAD verarbeitet?

In VermCAD können verschiedene Arten von Vermessungsdaten verarbeitet werden. Dazu gehören beispielsweise:

✔ Punktdaten
✔ Koordinaten
✔ Messdaten
✔ grafische Informationen
✔ Projektdaten
✔ weitere Fachdaten

🪜 Vorbereitung vor dem Import

Vor dem Import prüfen

Bevor Daten übernommen werden, sollten folgende Punkte kontrolliert werden:

✔ Welche Daten werden benötigt?
✔ Woher stammen die Daten?
✔ Welches Koordinatensystem wird verwendet?
✔ Sind die Daten vollständig?
✔ Gibt es bereits vorhandene Daten im Projekt?


Ziel der Prüfung

Fehlerhafte oder unvollständige Daten können später zu falschen Berechnungen oder falschen Darstellungen führen.

📂 Datenübernahme in VermCAD

Grundprinzip

Beim Import werden externe Daten in ein bestehendes Projekt übernommen. Dabei müssen die Daten richtig zugeordnet und die Einstellungen kontrolliert werden.


Wichtige Punkte während des Imports

Kontrollieren:

✔ richtige Datei ausgewählt
✔ richtiges Format verwendet
✔ richtige Zuordnung der Daten
✔ richtige Projekteinstellung

⚙ Koordinatensystem und Einstellungen prüfen

Warum ist das wichtig?

Vor allem bei Koordinatendaten ist es wichtig, dass die verwendeten Einstellungen mit den Daten übereinstimmen. Ein falsches Bezugssystem kann dazu führen, dass Punkte an einer falschen Stelle dargestellt werden.


Kontrolle vor der Übernahme

Prüfen:

✔ Welches Koordinatensystem besitzen die Daten?
✔ Passt es zum Projekt?
✔ Ist der richtige Lagestatus eingestellt?
✔ Sind Einheiten und Werte plausibel?

🔍 Kontrolle nach dem Import

Der Import ist erst nach der Prüfung abgeschlossen

Nach der Übernahme müssen die Daten kontrolliert werden. Nicht nur prüfen, ob der Import ohne Fehlermeldung durchgelaufen ist, sondern ob die Daten fachlich richtig übernommen wurden.


1. Vollständigkeit prüfen

Kontrollieren:

✔ Sind alle erwarteten Punkte vorhanden?
✔ Fehlen Daten?
✔ Wurde die komplette Datei übernommen?


2. Lage prüfen

Im Kartenfenster kontrollieren:

✔ Liegen die Punkte dort, wo sie erwartet werden?
✔ Passt die Lage zu vorhandenen Daten?
✔ Gibt es auffällige Verschiebungen?


3. Inhalt prüfen

Zusätzlich prüfen:

✔ Stimmen Punktnummern?
✔ Sind Höhen vorhanden?
✔ Sind Attribute richtig übernommen?

📍 Punktkontrolle nach Datenübernahme

Warum Punkte kontrollieren?

Punkte bilden die Grundlage für weitere Berechnungen und Auswertungen. Fehlerhafte Punktdaten können sich auf alle folgenden Arbeitsschritte auswirken.


Prüfschritte

Kontrollieren:

✔ Punktnummern vergleichen
✔ Koordinaten prüfen
✔ Punktlage kontrollieren
✔ vorhandene Daten vergleichen
✔ auffällige Punkte untersuchen

💡 Praxistipp

Ein erfolgreicher Import bedeutet nicht automatisch, dass die Daten richtig sind. Die wichtigste Kontrolle ist der Vergleich:

➡ Stimmen die importierten Daten mit der erwarteten Situation überein?
