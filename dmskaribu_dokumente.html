📌 Zweck der Dokumentenverwaltung

Arbeiten mit Katasterunterlagen

Die Dokumentenverwaltung ermöglicht das Anzeigen und Verwalten von vorhandenen Unterlagen innerhalb von DMS-Karibu. Dokumente können recherchiert, geprüft und für weitere Arbeitsschritte verwendet werden.

🖱 Schritt-für-Schritt Anleitung

1️⃣ Dokument auswählen

Nach einer erfolgreichen Recherche wird der passende Datensatz ausgewählt. Anschließend können die zugehörigen Dokumente angezeigt werden.

📷 Screenshot: Dokumentauswahl

2️⃣ Dokumentinformationen prüfen

Vor dem Öffnen sollte geprüft werden, ob das richtige Dokument ausgewählt wurde. Dabei können Informationen zum Dokument kontrolliert werden.

📷 Screenshot: Sachdaten / Dokumentinformationen

3️⃣ Dokumentvorschau öffnen

Über die Vorschau können vorhandene Dokumente angezeigt und kontrolliert werden. Dies ermöglicht eine schnelle Prüfung ohne zusätzliche Bearbeitungsschritte.

📷 Screenshot: Vorschau

4️⃣ Dokument weiterverwenden

Je nach Aufgabe können die Informationen oder Unterlagen für weitere Arbeitsschritte genutzt werden. Beispiele:

✔ Prüfung von Katasterunterlagen
✔ Vorbereitung von Vorgängen
✔ Bearbeitung von Aufträgen

💡 Praxis-Tipp

Vor der Weiterverarbeitung immer prüfen, ob das richtige Dokument und der richtige Datensatz geöffnet sind. Gerade bei umfangreichen Akten können mehrere ähnliche Unterlagen vorhanden sein.

⚠ Häufige Fehler

Typische Probleme:

❌ falsches Dokument geöffnet
❌ Dokument nicht geprüft
❌ falscher Datensatz verwendet
