📥 Datenimport

Übernahme von Vermessungs- und Katasterdaten in das Berechnungsprojekt

📌 Übersicht

Zweck des Datenimports

Damit alle benötigten Vermessungs- und Katasterdaten im Berechnungsprojekt verfügbar sind, werden die entsprechenden Dateien importiert. Die importierten Daten bilden die Grundlage für die weitere Bearbeitung.

📄 NAS-ALKIS-Datei importieren

Die NAS-Datei enthält Informationen aus dem Liegenschaftskataster. Durch den Import werden die vorhandenen Katasterdaten in das Berechnungsprojekt übernommen und stehen für die weitere Bearbeitung zur Verfügung.


Ablauf:

Transfer
⬇
Datei Import
⬇
NAS-ALKIS

🔢 XML-Nummernreservierung importieren

Zusätzlich kann eine XML-Datei mit der Nummernreservierung übernommen werden. Diese enthält Informationen zu vergebenen Punktnummern und unterstützt die weitere Bearbeitung des Projektes.


Ablauf:

Transfer
⬇
Datei Import
⬇
XML-Nummernreservierung

🔎 Kontrolle nach dem Import

Nach dem Import müssen die übernommenen Daten geprüft werden. Dabei wird kontrolliert, ob die benötigten Daten vollständig vorhanden sind und korrekt übernommen wurden.


Kontrolle:

✔ Daten vollständig vorhanden
✔ Katasterinformationen übernommen
✔ Projektgrundlage korrekt

💡 Praxis-Tipp

Ein sauberer Datenimport ist eine wichtige Grundlage für die folgenden Arbeitsschritte. Fehler oder fehlende Daten können die weitere Bearbeitung beeinflussen.

⚠ Achtung

Vor der weiteren Bearbeitung sollten die importierten Daten immer kontrolliert werden. Nur mit einer korrekten Datengrundlage können die nächsten Arbeitsschritte zuverlässig durchgeführt werden.
